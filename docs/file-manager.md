# 实时本机文件管理

规格：[Issue #11](https://github.com/ChenWingYan/Cic_virtual_desktop/issues/11)。2026-11-02 用户确认本范围替代 #5 的只读限制，沿用 [ADR 0001](adr/0001-managed-content-and-public-contracts.md) 的受管理内容及窄 preload 边界。术语见根 GLOSSARY.md。

## 使用范围

首页的文件管理器提供“此电脑”、桌面、下载、文档，以及 Windows 识别的本地固定磁盘和移动盘。网络共享和映射网络盘不进入授权根目录。访问遵循当前 Windows 账户权限。位置栏可以直接输入本地绝对目录。

文件和文件夹支持多选、复制、剪切粘贴、重命名、删除、新建文件夹。同名目录合并，内部同名文件逐个询问覆盖、跳过或保留两份；文件与目录类型冲突可跳过或保留两份。跨盘移动逐项复制成功后才删除对应源文件，失败保留已完成部分并反馈，不自动重试。当前不提供编辑、预览、软件安装和启动外部程序。

删除先确认移入回收站。系统回收站拒绝后，再次询问是否永久删除，默认不执行。确认界面位于逻辑画布内，接受相同的方向和比例补偿。

外部下载按磁盘实际名称、大小和修改时间显示，包括临时文件。文件出现不代表下载完成。内置浏览器继续阻止上传和下载。

## 刷新与插拔

当前目录使用文件系统监听触发核对，750ms 周期核对补偿通知丢失，并比较大小、时间、名称和种类。独立 PowerShell 辅助进程每 900ms 发现本地固定磁盘和移动盘，避免盘符发现阻塞界面。文件管理器隐藏时释放目录监听和轮询；再次进入核对之前的位置。磁盘辅助进程随桌面生命周期关闭。

插入磁盘只更新入口，不自动跳转。当前目录因拔盘、删除或权限变化不可访问时，返回此电脑并提示。刷新保留滚动位置及仍存在的多选项。正常条件下目标为文件变化 1 秒内、系统识别磁盘变化后 2 秒内更新；大型目录、慢盘及系统阻塞可能超出目标，不能把本机临时目录的测量外推到全部设备。

## 自身文件保护与契约

主进程保护应用根目录（开发态为项目目录）、Electron userData、sessionData 和 logs 的实际位置。允许浏览及复制普通自身文件出来，禁止写入、删除、移动、改名及通过上级目录破坏它们。平台访问位置通过 `app.getPath` 获取。开发及测试使用 `CIC_DESKTOP_DATA_DIR` 隔离运行数据。

`app-shell/src/modules/local-files/public/api.js` 暴露 `createLocalFiles`。主进程提供本地根目录、受保护路径、回收站及确认回调；服务提供 `open`、`close`、`subscribe`、`list`、`operate`。界面从 `features/file-browser/public/api.ts` 创建面板，跨进程使用 `shared/contracts/files.ts` 的纯数据类型。

preload 只暴露浏览、位置、操作、问题回答及快照订阅。每个文件 IPC 入口验证可信桌面主框架的 URL 和对象身份，外部网页不能获得文件能力。主进程重新校验操作枚举、文件名、实际路径与当前可访问根目录；UNC、设备路径及 NTFS 数据流路径被拒绝。

写操作拒绝符号链接、目录联接路径和多硬链接文件；递归操作检查嵌套项。链接可浏览其允许范围内的实际目录，但文件传输不复制链接。覆盖普通文件先复制到同目录独占临时文件，成功后再替换，避免复制中断先清空旧文件；未存在目标独占创建，并在提交前检查目标是否变化。服务内文件变更串行化。

这些规则约束本应用发起的文件操作。它们不防御其他进程并发修改链接、权限或文件路径；不构成 Windows 安全隔离。运行其他软件、锁定文件与权限错误均由系统决定，并通过操作结果报告。

## 验证入口

- `npm test`：临时目录验证外部变化、盘符消失、操作与冲突、自身路径、父目录、链接和硬链接保护、回收站失败二次确认。
- `npm run typecheck`、`npm run build`：界面契约及构建。
- `npm run smoke:files`：真实 Electron 操作外部临时目录，验证列表更新、大小变化、多选和滚动保留、复制、重命名、同名保留两份、真实回收站、可信来源检查和四方向界面；产物在 artifacts。
- `npm run smoke`、`npm run smoke:browser`：校准及浏览器回归，包含保持下载阻止策略。

现场仍须使用目标设备验证 U 盘实物插入、拔出、传输中断与跨盘移动，测量刷新延迟，并核对实体屏方向及触摸。自动化模拟磁盘消失不等同于实物验收。

API 依据：[Electron shell.trashItem](https://www.electronjs.org/docs/latest/api/shell#shelltrashitempath)、[Node 文件系统监听约束](https://nodejs.org/api/fs.html#fswatchfilename-options-listener)。系统通知可能丢失，因此保留周期核对。
