# 以受管理内容和公开契约组织虚拟桌面

状态：accepted，2026-10-30。用户已授权采用推荐设计；实现及设备验证尚未进行。

采用 Electron JavaScript 外壳与 Vite TypeScript 界面。显示几何、内容承载、桌面会话、本机文件、配置和查验接入各自通过公开契约提供能力。显示几何不依赖 Electron；本机能力经受控 preload 暴露给可信界面。按 public 入口组织可提取的接口及契约类型，内部实现保持可替换。

选择应用内受管理内容，是因为任意外部 EXE 不会自动接受本软件的旋转和比例补偿。首期不做驱动、原生窗口捕获注入或查验后端重写。C++20 仅在原型证明必要时引入。

代价是需要验证网页和查验内容的渲染、焦点及输入。离屏渲染是首先验证的候选，尚未被批准为生产实现。中文输入、弹窗或视频无法达到需求时，重新评估内容承载方案，不以主页旋转效果代替真实网页验证。
